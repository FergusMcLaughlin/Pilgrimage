# Installed release

Godot GIF 1.1.1 from https://github.com/BOTLANNER/godot-gif/releases/tag/1.1.1

Archive SHA-256: `9ce6f31ce310411e34bcff0ae243c2731dc234370c226b1eaef241ace0aab2be`

This GDExtension registers its importers automatically when the editor loads it. It does not require an entry in Project Settings > Plugins. GIF import options support SpriteFrames and AnimatedTexture.

The six card GIFs in both asset folders are configured as AnimatedTexture imports so they can be assigned to TextureRect and preserve their original per-frame GIF durations. All twelve imports were checked in Godot 4.7.2: frame counts, dimensions and durations match their source GIFs.
