# Codex Outputs

This Obsidian vault is reserved for outputs generated by Codex when requested.

## Folders

- `Outputs/` - generated notes, summaries, checklists, plans, and reports.
- `Templates/` - reusable note formats for future Codex output.

## Usage

Ask Codex to write an output here and name the kind of note you want. If no specific filename is given, use a clear dated filename in `Outputs/`.
